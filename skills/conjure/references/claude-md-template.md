## Extraction Rules

1. **Commands**: Read `package.json` scripts section, `Makefile`, and CI workflow files. Prioritize scripts that match common developer workflows: `dev`, `start`, `build`, `test`, `lint`, `format`, `migrate`, `deploy`.

2. **Project structure**: Run `ls` on the top-level directory and key subdirectories. Annotate directories with their purpose based on their contents.

3. **Conventions**: Check for:
   - `.editorconfig` — indentation, line endings
   - `.prettierrc*` — formatting rules
   - `.eslintrc*` / `eslint.config.*` — linting rules
   - `commitlint.config.*` — commit conventions
   - `.husky/` — git hooks
   - Recent git log messages — infer commit style

4. **Architecture**: Infer from:
   - Monorepo config files (nx.json, turbo.json, pnpm-workspace.yaml)
   - Directory structure (apps/, services/, packages/, libs/)
   - Communication patterns (HTTP clients, message queues, event emitters)
   - Entry points (main.ts, index.ts, server.ts)

5. **If updating existing CLAUDE.md**:
   - Preserve all existing content
   - Add or update the "Generated Skills" section at the bottom
   - Only modify other sections if the user explicitly asks
   - Add a comment `<!-- Updated by /conjure on YYYY-MM-DD -->` at the bottom
